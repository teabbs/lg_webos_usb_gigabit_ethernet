# Connecting a USB gigabit ethernet adapter LG WebOS TVs

LG WebOS-based smart TVs are great for their image quality and features, but they lack an essential thing for modern network connectivity - a gigabit ethernet connection. The solution is to connect to your network via a USB gigabit network adapter, but you have to find the correct one for your exact model (or buy a specific model that supports it). Some TVs don't support USB adapters at all, some support one or two, some (mostly premium models) support plenty. This doc has a few tips on how to get what you can.

The most comprehensive forum thread on this topic: https://webos-forums.ru/topic4796.html (in Russian)

The first page has a link to a manual on unpacking your TV's firmware and discovering exactly what USB ethernet chipsets it supports for USB ethernet connection (if any). The manual also provides some reference for finding a supported adapter for a specific driver.
